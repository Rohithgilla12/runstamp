# PRODUCT.md

## Register

product

## Users

Vegetarian / serious runners who log 60–80 km/week across 4–5 sessions, often travel and run in new cities, post selectively to Instagram Stories after long runs, and have opinions about training. They already use Strava or Apple Watch as their tracker — Runstamp is the post-run tool for composing share images, collecting place stamps, and reading training honestly.

## Purpose

Collect a stamp for every run. Open-source mobile app (iOS + Android via Expo) that turns completed runs into shareable artifacts: post-run share-card editor, analytics, a passport for cities you've run in, and an achievement / stamp catalogue. Not a tracker — reads runs from Strava / Apple Health.

## Brand personality

Quiet · earned · collectible.

Voice is plain, runner-coded, slightly dry. The app whispers; the run did the work; the stamp is the keepsake.

## Aesthetic direction

Postage / passport / postmark world. Reference triangle: Things 3 / Bear / Linear (indie craft), Apple Wallet / Mail passes (layered card surfaces), Polaroid / Field Notes / Riso (tangible print character).

## Anti-references

- Duolingo — gamified, over-emoji'd
- Nike Run Club — aspirational sloganeering, cinematic black
- Strava Premium — generic share cards, paywalled analytics

## Design principles

1. Quiet over loud
2. Real-world materials (perforations, postmarks, halftone, ink bleed)
3. Type carries the load (Instrument Serif · Geist · JetBrains Mono)
4. One warm pop per surface (solar accent)
5. Empty states look like the rest of the app
6. Information answers a question; decoration doesn't

## Accessibility

WCAG AA. 44pt minimum tap targets. Screen-reader labels on icon-only buttons. Don't rely on color alone for state.
